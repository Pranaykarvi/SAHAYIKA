# Sahayika

Sahayika connects rural Indian women in Self-Help Groups to economic opportunity through AI-assisted matching that is always verified by a professional social worker and always decided on by the group itself. This repository holds two independently deployed applications linked only by a generated OpenAPI contract: [`backend/`](backend/README.md) is the Express + TypeScript API that owns all data and logic, and [`frontend/`](frontend/README.md) is the Next.js web application that owns all presentation. See each folder's README for setup and an honest account of what is and is not implemented, and [CLAUDE.md](CLAUDE.md) for the project's invariants. All data in this build is synthetic demonstration data and is flagged as such in the database and badged in the UI. The full design specification this build implements a subset of is preserved in this file's git history (`git show bd36fc4:README.md`).
